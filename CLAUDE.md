# CLAUDE.md — worldsim-ui

Правила для Claude Code в этом репо.

## Что это

UI текстовой RPG worldsim: три равные панели Беседа | Локация | Действие.
Phase 1 — прототип на фикстуре (без LLM). Phase 2 — подключение HTTP API
оркестратора через уже существующий интерфейс `WorldEngine` (отдельная спека).

## Жёсткие правила

1. ЭМОДЗИ ЗАПРЕЩЕНЫ — в коде, UI, коммитах, документации, отчётах.
2. Тексты внутри UI — русские. Код, идентификаторы, commit-сообщения — английские.
3. Общение с пользователем — русское.
4. Шрифт UI — только гротеск (system-ui), серифов нет.
5. Тема warm: фон #1d1b18, панели #211e1a, текст #e9e0cd, акцент #c0892e —
   токены заданы в `src/index.css`, новые цвета добавлять туда же, не хардкодить.
6. Иконки — только код/вектор (SVG-глифы в `src/components/glyphs.tsx`),
   никаких генеративных картинок. Плитки — щиты (clip-path), цвет из хеша id.

## Ветки

Работа — в `dev` (прямой push разрешён). В `staging` — только PR из `dev`
с 1 approve, в `main` — только PR из `staging` с 1 approve. Прямой push
в `staging`/`main` заблокирован.

## Границы

- `WorldEngine` (`src/engine/`) — единственная граница между UI и миром.
  UI не лезет в фикстуру напрямую.
- TS-типы канона (`src/types/canon.ts`) — зеркала pydantic-моделей из
  `worldsim-workspace/packages/schemas/`. Канон менять можно только там
  (в workspace), здесь — только отражать.
- Соседние репо в `../` — только чтение.
